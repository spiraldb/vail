## One concrete missed demand boundary

Pursue H012's FLAT aligned matrix map for row-captured ordinary Struct fields. Current Python matrixtable.py840 rewrites `mt.row_meta` to an AlignedMapInput(row,row_meta,WHOLE declared type); a subsequent `.small` remains GetField over that capture. expressions.rs6060 collects each capture's ORIGINAL whole dtype and declares a full capture frame column. aligned_matrix_map.rs403 locates the full row field; when row selection is nonidentity it takes that full field BEFORE any nested projection. Lines445–455 then restore the full capture type, construct REE and immediately Arrow-cast it into a dense per-entry array. A body that only reads row_meta.small can therefore copy unused row_meta payload into every entry before the ordinary GetField runs.

This is a source fact, not a measured current bottleneck. Public class: per-entry computations/aggregates combining an entry value with a nested row annotation and a collection callback, such as `DP + sum(row_meta.small_array)`, where row_meta also contains a large unused sibling. A collection body is not in expressions.rs6041 scalar_rows whitelist, so it is eligible to reach evaluate_flat. Actual optimizer simplification could hoist/eliminate the example; that is a reason to confirm the public plan/sample first, never force a private route.

Existing COL handling already does the desired kind of work: expressions.rs5973 ColumnDemand gathers static GetField paths (DAG-memoized, whole-value use means all), and aligned_matrix_map.rs343 projects borrowed ordinary Struct fields BEFORE column take. Reuse that concept for row capture keys; do not invent another scalar evaluator or manual kernel. Existing project_column_array790 demonstrates safe Struct view construction preserving parent validity. Prepare selected Fields/types/indices once; bind actual arrays/null masks at batch time. Project BEFORE BOTH selected-row take and REE-to-dense decode, not after them. Output math/callback semantics and original producer execution remain unchanged.

Initial scope: row captures and static nested ordinary-Struct paths ONLY, no arrays-of-Struct/dictionary/Set/Call/Locus descriptor pruning. Whole-value use, unsupported path/type or uncertain effect/capture semantics retains the WHOLE original capture. Preserve original child metadata and result type, logical ancestor nulls, lazy sparse-entry guards, callback captures and original error behavior. Existing contextual typing/lowering memo must see the projected physical frame schema; avoid retyping shared DAGs quadratically. Scalar-row path already borrows row metadata and is a required unchanged control, not an alleged unresolved per-row recompilation problem.
