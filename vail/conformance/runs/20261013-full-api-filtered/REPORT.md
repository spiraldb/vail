This is the upstream Python API suite redirected to Vail, not Scala tests or a stock Hail run. Hail initialization, backend health/flags decorators, and two sample Matrix fixtures are adapted. Tests and assertion bodies are preserved. The full selection and reasons are in [selection.json](selection.json).

One highly unbalanced zip join exceeded the native deadline. See [timeout analysis](SLOW_ZIP_JOIN.md).

## Limitations

- Per-test limit: 120 seconds. One native test ignored Python alarm delivery; its module was terminated after recording the exact node, and remaining definitions were attempted in independent processes. Worker subprocesses also enforce 120-second limits. A timeout is not labelled an assertion mismatch.
- Legacy `.ht`/`.mt` fixtures are retained where they are part of public read/import tests, but Vail lacks the legacy reader. Only the two existing sample VCF snapshots are rebuilt by the adapter.
- Missing public packages and missing mixed-test fixture dependencies are reported explicitly; they are not counted as passes or silently deselected.
- The upstream-skipped JVM codec fixture generator was excluded during the purpose audit. An early body preflight stopped in fixture construction before reaching its backend calls; it is not included in any count.
- Numerical/collection behavior deliberately covered by the incompatibilities document is identified as a documented limitation where the first error makes that clear.
