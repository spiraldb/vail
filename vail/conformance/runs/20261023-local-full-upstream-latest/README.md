# Full local upstream benchmark, 23 October 2026

Frozen main `1c00d2d6fb8a5b029b3014f57dd3942e904afce8`; normally built native SHA256 `3f8b5061f4d9fc1b0e8b9ec26e68fb3847d547511fdd87c72ae6ec06182b2201`. Stock PyPI Hail 0.2.139, Java 11, Spark 3.5.9. Same M3 Max laptop, 14 logical CPUs/96 GiB RAM; both engines configured concurrency 32. Engines and cases ran serially, with three fresh query samples per engine. Query-only wall/CPU excludes engine initialization and fixture preparation. CPU/RSS sampled at 10 Hz across process trees, retaining exited child counters; children shorter than sampling interval can be missed. Observed min/max are descriptive ranges, not confidence intervals.

All 108 upstream inventory cases are accounted for: 85 paired successes (three samples each), four existing Vail failures, 15 unavailable exact fixture cases, and four upstream skips. No representative substitution. Hail/Vail geometric mean ratios: 6.146 wall, 6.598 CPU. Ratios of sums of case medians: 2.017 wall, 2.324 CPU. Vail wall time is more than 10% faster in 83/85 pairs; Hail is faster in two: BGEN info_score and many_aggs_col_wise. These are local results, not direct cloud speedup estimates.

The first phase used available exact fixtures. A separate serial preparation phase created canonical range fixtures, Hail profile25 and many_ints native fixtures from cached raw inputs, and an independent Hail BGEN index. Initial Hail BGEN setup failures used an incompatible Vail index; those invalid setup attempts are preserved and excluded. The gap phase ran only newly available cases, reusing already successful Vail samples with exact source/native hash checks. Two Hail cases failed Spark TaskResultLost/Netty file transfer in every gap repetition: downsample_dense and mt_localize_and_collect. A final separate Hail-only retry changed only spark.driver.host and spark.driver.bindAddress to 127.0.0.1; all six retries passed. Original failed logs remain in gapfill. Final per-case reports record their source; no reused sample is counted twice.

Remaining unavailable exact fixtures: seven many_strings cases (341,994,020-byte raw absent), six full gnomad_dp_sim cases (250,000×1,000 fixture absent), two random_doubles cases (1,001,296,960-byte raw absent). Large substitute fixtures were not generated. Existing Vail failures: range_array_range_force_count panic, two unsupported row/column matrix exports, and absent experimental multi-write API. `nonpasses.json` lists every status/error per repetition.

Full interactive charts/table: aggregate-report.html. Exact values, N, median/min/max: case-medians.csv; worst wall ratio first: case-medians-worst-first.csv. Raw query telemetry and process samples are in the initial/gapfill/loopback phase directories. Fixture preparation receipts are in gap-fixtures.
