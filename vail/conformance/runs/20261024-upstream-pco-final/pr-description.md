PCO stores compact non-null numeric values, so selecting logical rows currently ranks the entire unsliced validity and has no encoding-specific batched take kernel. This adds optional versioned logical page ends and shared immutable page descriptors, letting take, compact PiecewiseSequence ranges, slices and scalar probes validate/rank touched logical pages and decode selected pages once per operation.

Absent and unknown optional metadata use the legacy path; compressed page payloads and existing protobuf fields remain unchanged. Raw sliced PCO serialization now errors because its in-memory offsets are absent from the historical wire contract. Writers explicitly execute the selected slice, and optionally recompress it, before serialization; no new Slice wire encoding is introduced. Validity cost still depends on the validity encoding's slice implementation, and retained probes can accumulate the full decoded array over their lifetime.
